\begin{frame}{Поверхность волатильности на разреженном рынке}
    Поверхность $\sigma(k, T)$ нужна для оценки опционов и рисков, но рынок показывает её в немногих точках.
    \begin{block}{Цель}
        Проверить, помогает ли история рынка восстанавливать поверхность по малому числу текущих сделок, и предложить метод, который эту историю использует.
    \end{block}
    \begin{block}{Проблема}
        SVI и SSVI строят поверхность по сделкам одного дня. Когда сделок мало, им не хватает данных о крыльях и о сериях без сделок.
    \end{block}
    \begin{block}{Подход}
        \begin{enumerate}[1)]
            \item Скрывать реальные сделки и восстанавливать их по оставшимся.
            \item Сравнивать методы текущего дня с методами, которые используют историю.
            \item Вместе с точностью проверять статический арбитраж.
        \end{enumerate}
    \end{block}
\end{frame}

\begin{frame}{Что видно на рынке за один день}
    Расчётная кривая биржи плотная, но это модель биржи. Реальные наблюдения "--- сделки: их мало и они шумные.

\begin{frame}{Постановка задачи}
    Сделки дня $t$: $\mathcal{O}_t = \{(e_i, k_i, \sigma_i, n_i)\}$ "--- серия, денежность $k = \ln(K/F)$, волатильность, число минут со сделками. История $\mathcal{H}_{t-1}$ "--- всё, что известно к началу дня, включая вчерашнюю расчётную кривую $S_{t-1}$.
    \begin{block}{Восстановление}
        Видна часть сделок $\mathcal{O}^{\mathrm{vis}}_t$. Метод строит $\hat\sigma_t(e, k)$ по $(\mathcal{O}^{\mathrm{vis}}_t, \mathcal{H}_{t-1})$. Ошибка (RMSE, п.п. волатильности) считается на скрытых сделках.
    \end{block}
    \begin{block}{Отсутствие статического арбитража}
        <<Бабочка>>: цена колла выпукла по страйку. <<Календарь>>: полная дисперсия $w = \sigma^2 T$ не убывает по сроку.
    \end{block}
    \begin{block}{Прогноз}
        В конце дня $t$ строится $\hat\sigma_{t+h|t}(e,k)$ только по истории $\mathcal{H}_t$. Ошибка считается на всех сделках дня $t+h$.
    \end{block}
\end{frame}

\begin{frame}{Предлагаемый метод: три шага}
    \begin{enumerate}
        \item \textbf{Начальное приближение} "--- вчерашняя расчётная кривая биржи $S_{t-1}(e, k)$.
        \item \textbf{Поправка по видимым сделкам} "--- гауссовский процесс:
        \[
            \sigma_i = S_{t-1}(e_i,k_i) + \delta_t(x_i,e_i) + \varepsilon_i,\qquad \delta_t\sim\mathcal{GP}(0,K_\theta),\qquad \varepsilon_i\sim\mathcal{N}\bigl(0,\,a^2+b^2/n_i\bigr).
        \]
        Ковариация $K_\theta$: общий сдвиг уровня, наклона и кривизны, сдвиги серий, локальные отклонения. Двенадцать параметров оценены по сделкам прошлого года (максимум правдоподобия). Оценка поправки:
        \[
            \hat\delta_t(q)=\mathbf{k}_q^{\top}(\mathbf{K}+\mathbf{S})^{-1}\mathbf{r}.
        \]
        \item \textbf{Контроль арбитража} "--- линейным программированием ищется ближайшая поверхность без <<бабочки>> и <<календаря>> на сетке.
    \end{enumerate}
    \medskip
    История используется дважды: как вчерашнее состояние рынка и как статистика поправок.
\end{frame}

\begin{frame}{Прогноз как начальное приближение}
    \textbf{Динамический вариант метода:} на шаге~1 вместо вчерашней кривой $S_{t-1}(e,k)$ берётся прогноз на один день
    \[
        \hat\sigma_{t|t-1}(e,k)=S_{t-1}\bigl(e,\;k\sqrt{T_{e,t-1}/T_{e,t}}\bigr)+\varphi_1\,\hat u_{t-1},\qquad \varphi_1=\E{Si/phi/1},
    \]
    где $\hat u_{t-1}$ "--- сглаженная разность между вчерашними сделками и вчерашней кривой.
    \medskip
    \begin{columns}[T]
    \begin{column}{0.5\textwidth}
        RMSE, п.п.: базовый метод $\rightarrow$ динамический
        \begin{itemize}
            \item скрыто 10\,\%: \E{Si/rmse/gp_af/random/0.1} $\rightarrow$ \E{Si/rmse/gp_dyn_af/random/0.1};
            \item скрыто 90\,\%: \E{Si/rmse/gp_af/random/0.9} $\rightarrow$ \textbf{\E{Si/rmse/gp_dyn_af/random/0.9}};
            \item скрыты крылья: \E{Si/rmse/gp_af/wings} $\rightarrow$ \textbf{\E{Si/rmse/gp_dyn_af/wings}};
            \item видно 5 контрактов: \E{Si/rmse/gp_af/topn/5} $\rightarrow$ \textbf{\E{Si/rmse/gp_dyn_af/topn/5}}.
        \end{itemize}
    \end{column}
    \begin{column}{0.5\textwidth}
        \begin{itemize}
            \item Точнее базового метода в 11 сценариях из 12, разности значимы.
            \item Выигрыш небольшой: сотые доли п.п.
            \item История используется трижды: вчерашняя кривая, вчерашние сделки, статистика поправок.
            \item На RTS выигрыша нет: там $\varphi_1=\E{RTS/phi/1}$.
        \end{itemize}
    \end{column}
    \end{columns}
\end{frame}

\begin{frame}{Нейросеть на тех же данных}
    \begin{columns}[T]
    \begin{column}{0.5\textwidth}
        \textbf{Что сравнивается}
        \begin{itemize}
            \item Сеть с вниманием по множеству видимых сделок (нейронный процесс): около 90 тысяч весов, среднее трёх сетей.
            \item Те же входы и то же начальное приближение, что у гауссовского процесса.
            \item Обучение на первом годе: сделки скрываются по тем же пяти схемам.
        \end{itemize}
    \end{column}
    \begin{column}{0.5\textwidth}

\begin{frame}{Что не подтвердилось и что с арбитражем}
    \small
    \begin{itemize}
        \item \textbf{Связи между сериями пользы не дали.} Вариант метода без них даёт ту же точность (разности до 0{,}02~п.п.).
        \item \textbf{Вчерашняя кривая иногда вредит.} При 10--70\,\% случайного скрытия вариант без неё точнее на 0{,}03--0{,}05~п.п.: в \E{Si/gap/worst} парах <<серия, день>> из \E{Si/gap/total} кривая биржи ошибается на \E{Si/gap/hist_rmse}~п.п. Динамический вариант сокращает число таких пар до \E{Si/gap_dyn/worst}.
        \item \textbf{Видны только две ближние серии.} Метод хуже вчерашней кривой на \E{Si/diff/gp_af/hist/far}~п.п.
        \item \textbf{Обучаемые модели прогноза.} Авторегрессия факторов помогает только от 5 дней, бустинг и нейросеть устойчивого выигрыша не дали.
        \item \textbf{Арбитраж.} Расчётная кривая биржи нарушает условия в \E{Si/arb/any_days/full/moex_today}\,\% дней (зона $|z|\le 2$). Исправление убирает нарушения. При случайном скрытии точность не страдает (\E{Si/arb/rmse_before/sparse/gp} $\rightarrow$ \E{Si/arb/rmse_after/sparse/gp}~п.п.), при пяти видимых контрактах оно стоит \E{Si/diff/gp_af/gp/topn/5}~п.п.
        \item \textbf{RTS.} При 90\,\% скрытия: \E{RTS/rmse/gp_af/random/0.9} против \E{RTS/rmse/cb_ssvi/random/0.9}~п.п. у SSVI. При 10--30\,\% разница с SSVI незначима. Прогноз и динамический вариант на RTS выигрыша не дали.
    \end{itemize}
\end{frame}

\begin{frame}{Выводы и дальнейшие шаги}
    \begin{enumerate}[1)]
        \item Предложен метод: начальное приближение из истории + поправка с выученной по истории ковариацией + исправление арбитража.
        \item На годе реальных сделок по Si метод точнее квадратичной улыбки, SVI и SSVI во всех 12 сценариях; выигрыш растёт с разреженностью. На контрольном периоде результат подтвердился.
        \item История полезна в двух видах: выученная статистика поверхности "--- всегда, вчерашнее состояние рынка "--- при сильной и структурной разреженности.
        \item Прогноз улучшают перенос кривой в координате $x$ и поправка по вчерашним сделкам: сделки опережают кривую биржи.
        \item Нейросеть на тех же данных даёт близкую точность. Связи между сериями точности не добавили.
        \item Далее: проверка защиты от ошибочной кривой на новых данных, исправление арбитража с меньшей потерей точности, ежедневный сбор заявок.
    \end{enumerate}
\end{frame}
