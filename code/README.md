# Код

Исходный код к работе: загрузка и обработка данных MOEX, построение поверхностей, модели и визуализация результатов.

> [!IMPORTANT]
> Jupyter-ноутбуки используются только для визуализации. Основной код храните в Python-скриптах.

## Установка

Клонируйте репозиторий:
```bash
git clone https://github.com/masbalt/diplom.git
cd diplom
```

Установите зависимости:
```bash
pip install -r code/requirements.txt
```

## Структура

| Путь | Назначение |
|:---|:---|
| `main.py` | **единственная точка запуска**: данные → синхронизация → пилот → основной эксперимент → рисунки |
| `config.py` | все параметры экспериментов и описание их потока |
| `figures.py` | рисунки по сохранённым таблицам (вычисления не повторяет) |
| `ivs/iss.py` | клиент MOEX ISS с дисковым кэшем |
| `ivs/data.py` | загрузка итогов торгов и сборка дневных досок |
| `ivs/contracts.py` | разбор кодов опционов, справочник серий (экспирация, базовый фьючерс) |
| `ivs/black76.py` | модель Блэка для маржируемых опционов (r = 0), обращение в IV |
| `ivs/moex_curve.py` | кривая волатильности НКЦ, по которой биржа считает расчётные цены |
| `ivs/board.py` | дневная доска в OTM-соглашении: F по паритету, IV расчётных цен и сделок |
| `ivs/intraday.py` | IV сделок, синхронизированная с фьючерсом по минутным свечам |
| `ivs/recon.py` | простые методы восстановления: квадратичная улыбка, SVI по сериям, вчерашняя кривая с поправкой |
| `ivs/ssvi.py` | SSVI — классический метод текущей доски без арбитража по построению |
| `ivs/gp.py` | предлагаемый метод: вчерашняя кривая + поправка гауссовским процессом, оценка параметров по истории |
| `ivs/arbitrage.py` | статический арбитраж на сетке: проверка «бабочки» и «календаря», исправление линейным программированием |
| `ivs/pilot.py` | пилот: скрытие сделок, восстановление, бутстреп-интервалы, TeX-макросы с числами |
| `ivs/experiment.py` | основной эксперимент: обучение на первом годе, проверка на втором, 12 сценариев скрытия, варианты метода, устаревание истории, арбитраж, режимы |
| `ivs/textables.py` | числа и строки таблиц статьи (`paper/generated/exp_*.tex`) по сохранённым таблицам |
| `tests/` | юнит-тесты на синтетических данных |
| `scripts/download_moex.py` | загрузка месячных/дневных срезов по нескольким активам (для аудита) |
| `scripts/sync_trades.py` | синхронизация сделок для произвольного периода |
| `scripts/audit_moex.py` | статистики аудита данных и графики |
| `scripts/collect_live_board.py` | сбор текущих bid/ask (исторических стаканов в бесплатном ISS нет) |

## Запуск

Данные и кэш ISS складываются в `data/` (в git не попадают).

```bash
python -m unittest discover -s code/tests   # юнит-тесты, секунды
python code/main.py --quick                 # тестовый прогон пилота на одном месяце, ~1 мин из кэша
python code/main.py                         # всё для Si: ~25 мин из кэша, первый запуск качает данные (~1 ч)
python code/main.py --asset RTS --stages data sync experiment   # проверка переносимости на RTS
python code/main.py --stages figures        # перерисовать рисунки и TeX-таблицы по сохранённым таблицам
```

Порядок для статьи: сначала полный прогон по Si, затем по RTS, затем `--stages figures` — последний шаг
добавит числа RTS в `paper/generated/`.

Результаты:

- пилот — `reports/tables/pilot_*_Si.*`, числа для слайда — `paper/generated/pilot_numbers.tex`;
- основной эксперимент — `reports/tables/exp_*_{Si,RTS}.*` (RMSE по сценариям, разности с интервалами,
  разбивки, варианты метода, устаревание истории, арбитраж, режимы, интервалы), оценённые параметры —
  `reports/tables/gp_params_*.json`, результаты по каждой скрытой сделке — `data/processed/exp_results_*.csv.gz`;
- рисунки (PDF и PNG) — `reports/figures/`, числа и таблицы статьи — `paper/generated/exp_*.tex`.

Разбиение по времени: параметры предлагаемого метода оцениваются на `TRAIN_RANGE`
(02.10.2024 – 30.09.2025), все показатели качества считаются на `TEST_RANGE` (01.10.2025 – 30.09.2026).

Аудит данных (несколько активов, месячные срезы с 2012 г.):

```bash
python code/scripts/download_moex.py --data-dir data \
    --monthly 2012-01:2026-09 --monthly-assets Si RTS BR MIX GOLD CNY \
    --daily 2024-10-01:2026-09-30 --daily-assets Si RTS
python code/scripts/audit_moex.py --data-dir data --out reports
```

Сбор текущих котировок (по расписанию, например раз в час в торговое время):
```bash
python code/scripts/collect_live_board.py --data-dir data --assets Si RTS
```
