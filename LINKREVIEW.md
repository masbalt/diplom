# LinkReview

- Рабочий обзор литературы по теме восстановления и прогнозирования поверхности подразумеваемой волатильности.
- В соответствии с требованиями курса собран пул **40+ релевантных работ**; в основной текст статьи войдут только наиболее важные.
- Для каждой работы указано, зачем она нужна: базовый метод, постановка, данные, ограничение или современный конкурент.
- Основной акцент сделан на работах последних 3–5 лет; старые статьи оставлены только как фундаментальные для теории опционов и безарбитражного построения поверхности.

> [!NOTE]
> Цель обзора — не перечислить публикации, а вывести исследовательский пробел: существующие методы хорошо решают либо статическое восстановление поверхности, либо прогнозирование на крупных ликвидных рынках, тогда как для разреженного рынка необходимо одновременно контролировать качество восстановления скрытых котировок, устойчивость к дефициту данных, временной прогноз и отсутствие статического арбитража.

## Основные методы для будущего сравнения

На текущем этапе наиболее обоснованный минимальный набор конкурентов:

1. **SVI / SSVI** — структурный безарбитражный параметрический baseline.
2. **Арбитражно-свободные сплайны Fengler** — непараметрический классический baseline.
3. **Deep Smoothing (Ackerer et al.)** — ключевой нейросетевой baseline для разреженной поверхности.
4. **U-Net / Transformer из Rodriguez Manzi (2026)** — современные сильные методы реконструкции.
5. Для прогноза: **persistence**, **Kalman-factor model**, **LSTM/ConvLSTM**, а затем более современные графовые/генеративные модели при достаточном объёме данных.

## Предварительный research gap

Обзор показывает, что уже нельзя считать новизной само применение нейросети, работу с разреженными поверхностями или добавление штрафа за арбитраж. Перспективный пробел находится в **совместной проверке восстановления и динамического прогноза на реально разреженном рынке**, где модель должна:
- восстанавливать намеренно скрытые котировки;
- устойчиво работать при разной плотности наблюдений;
- переноситься между режимами волатильности;
- не создавать статический арбитраж;
- давать полезный краткосрочный прогноз вне обучающего периода.

Эмпирической площадкой предполагается рынок опционов Московской биржи; окончательная постановка будет подтверждена после аудита доступности и плотности исторических данных.
